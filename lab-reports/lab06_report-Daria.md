## 📋 Короткий опис демонстраційної сторінки `/api-demo`

Сторінка `/api-demo` є інтерактивною клієнтською панеллю квіткового магазину Flowery. Вона дозволяє в реальному часі отримувати дані з бази SQLite через REST API та додавати нові записи без перезавантаження сторінки.

Сторінка розділена на 3 основні блоки:
1. **💐 Букети (товари):** відображення карткового каталогу букетів з цінами та емодзі, а також форма створення нового букета з валідацією назви й ціни.
2. **👩‍🌾 Клієнти та 🎟️ Промокод:** список зареєстрованих клієнтів, форма швидкого додавання покупця (з перевіркою формату телефону та дублікатів) і модуль розрахунку знижки за промокодом.
3. **💬 Відгуки:** список відгуків покупців зі зірковим рейтингом та форма відправки нового відгуку.

---

## 🔌 Використовувані ендпоінти API

| Блок | Метод | URL ендпоінта | Передавані дані (JSON Body) | Статуси відповідей |
| :--- | :--- | :--- | :--- | :--- |
| **Букети** | GET | `/api/v1/products` | — | 200 OK |
| **Букети** | POST | `/api/v1/products` | `name`, `category`, `price`, `emoji`, `description` | 201 Created / 400 Bad Request |
| **Клієнти** | GET | `/api/v1/customers` | — | 200 OK |
| **Клієнти** | POST | `/api/v1/customers` | `full_name`, `phone`, `email` | 201 Created / 409 Conflict |
| **Промокод** | POST | `/api/v1/promo/validate` | `code`, `subtotal` | 200 OK / 404 Not Found |
| **Відгуки** | GET | `/api/v1/feedback` | — | 200 OK |
| **Відгуки** | POST | `/api/v1/feedback` | `name`, `message`, `rating` | 201 Created / 400 Bad Request |
