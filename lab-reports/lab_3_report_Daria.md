## 3. Використані технології
- **Python 3 / Flask:** серверна частина, маршрутизація
- **Jinja2:** шаблони та успадкування від базового макета (`base.html`)
- **Tailwind CSS:** стилізація сторінок
- **Git / GitHub:** спільна розробка, використання окремих гілок та Pull Requests
- **venv:** віртуальне середовище, збереження залежностей у `requirements.txt`

## 4. Мій внесок

### 4.1. Сторінка «Про нас»
- Створено маршрут `/about` у файлі `app.py` (функція `about()`).
- Створено шаблон `templates/about.html`, який успадковує базовий макет `base.html`.
- **Вміст сторінки:** головний заголовок, історія заснування магазину, картки з перевагами та цінностями компанії, а також тематичні фотографії.
- **Стилізація:** виконана утилітами Tailwind CSS (використано `flex` та `grid` для розмітки, адаптивні класи `md:` та `lg:` для коректного відображення на різних екранах).

### 4.2. Сторінка «Каталог»
- Створено маршрут `/catalog` у файлі `app.py` (функція `catalog()`).
- Створено шаблон `templates/catalog.html`.
- **Вміст сторінки:** відображення карток товарів у вигляді сітки. Кожна картка містить зображення, назву квітів/букета, ціну та кнопку для замовлення.
- **Логіка даних:** дані про товари зберігаються у вигляді списку словників у файлі `app.py` та динамічно виводяться у шаблоні за допомогою циклу Jinja2 `{% for item in products %}`.
- **Адаптивність:** сітка карток налаштована на 1 колонку для мобільних пристроїв, 2 колонки для планшетів та 3–4 колонки для великих екранів (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).

Приклад реалізації маршруту в `app.py`:
```python
@app.route("/catalog")
def catalog():
```

## Висновки
Під час виконання лабораторної роботи я навчилася створювати маршрути та шаблони у фреймворку Flask, використовувати механізм успадкування Jinja2 для підтримки єдиного стилю всіх сторінок, будувати сучасну та адаптивну верстку за допомогою Tailwind CSS, а також ефективно працювати у команді з використанням систем контролю версій Git та GitHub. 

Серед основних складнощів можна відзначити первинне налаштування та підключення Tailwind CSS до Flask-проєкту, а також вирішення конфліктів під час злиття гілок. Результатом роботи є дві повністю функціональні та стилізовані сторінки («Про нас» та «Каталог»), які інтегровані в спільний проєкт.
