## 1. Особистий внесок у командну роботу

Як керівник команди (Team Leader) та відповідальна за базову архітектуру проєкту (Студент A), я виконала наступні завдання:

1. **Ініціалізація та налаштування проєкту:**
   - Створила публічний репозиторій на GitHub та налаштувала файли конфігурації `.gitignore` і `requirements.txt`.
   - Розгортала та налаштувала віртуальне середовище Python (`.venv`).

2. **Розробка ядра та маршрутизації (Flask):**
   - Написала головний модуль `app.py`, у якому визначила основні маршрути (`/`, `/about`, `/catalog`, `/contacts`).
   - Налаштувала обробку помилки 404 (custom 404 handler) та глобальний context processor для передачі загальних даних магазину (`SHOP`) у всі шаблони.
   - Створила початкову заглушку модуля даних `data.py`.

3. **Створення базового шаблону та дизайн-системи (Jinja2 + Tailwind CSS):**
   - Розробила спільний базовий шаблон `templates/base.html` з використанням Tailwind CSS CDN.
   - Налаштувала колірну палітру бренду Flowery за допомогою директиви `@theme`.
   - Реалізувала адаптивне головне меню з підтримкою мобільної навігації (кнопка-«гамбургер»).
   - Створила базовий шаблон для помилки 404 (`templates/404.html`) та початкові заглушки для всіх інших сторінок.

4. **Документування та координація:**
   - Створила файл `README.md` з описом ролей та інструкцією з запуску.
   - Провела рев'ю Pull Request від учасників команди та виконала остаточне злиття гілок.

## 3. Труднощі та їх вирішення

1. **Проблема:** Конфлікт портів під час запуску локального сервера Flask у середовищі macOS (помилка 403 / заповнений порт 5000 службою AirPlay).  
   **Рішення:** Налаштувала явну передачу параметра `port=5001` під час запуску `app.run(debug=True, port=5001)` для уникнення системних блокувань.

2. **Проблема:** Уникнення конфліктів злиття (merge conflicts) при одночасній розробці різними учасниками команди.  
   **Рішення:** Чітко розподілила файлову структуру проєкту між учасниками (Студент B — `index.html`, `about.html`; Студент C — `catalog.html`, `contacts.html`, `data.py`) та впровадила Git Flow із використанням окремих feature-гілок і Pull Requests.
