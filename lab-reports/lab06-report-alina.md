# ЗВІТ З ЛАБОРАТОРНОЇ РОБОТИ № 6

## Реалізація клієнтської взаємодії з REST API вебзастосунку Flowery

### 1. Мета роботи

Метою лабораторної роботи є набуття практичних навичок роботи з REST API у вебзастосунку, реалізація взаємодії клієнтської частини з сервером за допомогою JavaScript, обробка запитів і відображення отриманих результатів на вебсторінці.

### 2. Завдання роботи

У межах командного проєкту Flowery виконати частину завдань учасниці C:

- реалізувати клієнтський блок для перегляду та додавання клієнтів;
- забезпечити отримання списку клієнтів із REST API;
- реалізувати перевірку введених даних перед надсиланням запиту;
- реалізувати перевірку промокодів через REST API;
- відображати повідомлення про успішне виконання операцій та помилки;
- перевірити правильність роботи реалізованого функціоналу.

### 3. Використані технології та інструменти

Під час виконання лабораторної роботи використовувалися:

- **Python** — серверна частина вебзастосунку;
- **Flask** — вебфреймворк;
- **JavaScript** — реалізація клієнтської взаємодії з API;
- **HTML** — структура вебсторінки;
- **REST API** — обмін даними між клієнтською та серверною частинами;
- **SQLite** — база даних;
- **Visual Studio Code** — середовище розробки;
- **Git та GitHub** — система контролю версій і спільна робота над проєктом.

### 4. Хід виконання роботи

#### 4.1. Реалізація блоку клієнтів

У файлі `templates/partials/customers_block.html` реалізовано HTML-структуру блоку клієнтів.

Блок містить:
- форму для додавання нового клієнта;
- поля для введення імені, номера телефону та електронної пошти;
- кнопку збереження клієнта;
- область для відображення списку клієнтів;
- область для повідомлень про результат виконання операцій.

#### 4.2. Реалізація взаємодії з API

У файлі `static/js/customers.js` реалізовано JavaScript-функціонал для роботи з клієнтами.

Основні можливості:
- отримання списку клієнтів за допомогою GET-запиту до `/api/v1/customers`;
- додавання нового клієнта за допомогою POST-запиту;
- перевірка правильності введеного імені та номера телефону;
- оновлення списку клієнтів після успішного додавання;
- обробка помилок і відображення відповідних повідомлень користувачу.

Для виконання запитів використовуються спільні допоміжні функції `apiRequest()`, `showMessage()` та `setLoading()`.

#### 4.3. Реалізація перевірки промокодів

У клієнтській частині створено форму перевірки промокоду.

Користувач може ввести промокод і суму замовлення. Після надсилання форми JavaScript виконує POST-запит до `/api/v1/promo/validate`.

Сервер перевіряє:
- чи існує введений промокод;
- чи активний він;
- чи відповідає сума замовлення мінімальній вимозі;
- чи не закінчився термін дії промокоду.

Якщо промокод дійсний, система повертає інформацію про відсоток знижки, суму економії та остаточну суму замовлення.

#### 4.4. Серверна обробка промокодів

У файлі `routes/api_promo.py` реалізовано обробник перевірки промокоду.

Для цього використовується маршрут:

`POST /api/v1/promo/validate`

Обробник отримує дані у форматі JSON, перевіряє їх коректність, звертається до бази даних і повертає результат у форматі JSON.

У разі помилок сервер повертає відповідне повідомлення та HTTP-статус.

### 5. Перевірка роботи програми

Після реалізації функціоналу було виконано перевірку сторінки та основних операцій.

| № | Перевірка | Отриманий результат |
|---|---|---|
| 1 | Відкриття сторінки `/api-demo` | Сторінка успішно відкривається |
| 2 | Завантаження списку клієнтів | Клієнти відображаються на сторінці |
| 3 | Додавання нового клієнта | Клієнта успішно додано |
| 4 | Додавання клієнта з повторним номером телефону | Відображається повідомлення про помилку |
| 5 | Перевірка промокоду FLOWER10 із сумою 1000 грн | Знижка 10%, економія 100 грн, до сплати 900 грн |
| 6 | Перевірка неіснуючого промокоду ABC123 | Відображається повідомлення, що промокод не знайдено |
| 7 | Перевірка промокоду FLOWER10 із сумою 100 грн | Відображається повідомлення про недотримання мінімальної суми замовлення |

Також перевірено завантаження сторінки через Flask та правильність реєстрації маршруту `/api-demo`.

### 6. Результат роботи

У результаті виконання лабораторної роботи реалізовано клієнтський блок для перегляду та додавання клієнтів, перевірку введених даних, взаємодію з REST API та перевірку промокодів.

Реалізований функціонал дозволяє отримувати дані з сервера, надсилати нові дані, перевіряти промокоди та відображати результати операцій безпосередньо на вебсторінці.

### 7. Висновок

Під час виконання лабораторної роботи було отримано практичні навички створення клієнтської взаємодії з REST API за допомогою JavaScript та Flask. Було реалізовано роботу з клієнтами, перевірку промокодів, обробку помилок і відображення результатів запитів.

У процесі роботи закріплено навички використання HTTP-методів GET і POST, передавання даних у форматі JSON, перевірки введених даних та спільної роботи над програмним проєктом із використанням Git і GitHub.
