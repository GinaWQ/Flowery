### 2. Мета роботи

Метою лабораторної роботи є розробка та реалізація функціоналу бази даних для вебзастосунку Flowery, а саме створення таблиць для зберігання інформації про клієнтів і промокоди, реалізація операцій додавання, перегляду, пошуку, редагування статусу та видалення записів, а також забезпечення коректної взаємодії з базою даних.

### 3. Виконана робота

У межах командного проєкту Flowery я відповідала за реалізацію функціоналу керування клієнтами та промокодами.

#### 3.1. Створення таблиці клієнтів

Було створено SQL-файл `schema/02_customers.sql`, у якому реалізовано таблицю `customers`.

Таблиця призначена для зберігання інформації про клієнтів магазину та містить такі поля:

| Поле | Призначення |
|---|---|
| `id` | Унікальний ідентифікатор клієнта |
| `full_name` | Ім'я та прізвище клієнта |
| `phone` | Номер телефону |
| `email` | Електронна пошта |
| `address` | Адреса клієнта |
| `notes` | Додаткові примітки |
| `created_at` | Дата створення запису |

Для номера телефону передбачено унікальність, щоб уникнути дублювання клієнтів.

#### 3.2. Реалізація керування клієнтами

У файлі `routes/customers.py` було реалізовано функціонал роботи з клієнтами.

Основні можливості:

- додавання нових клієнтів;
- перегляд списку клієнтів;
- пошук клієнтів за ім'ям, номером телефону або електронною поштою;
- видалення записів клієнтів;
- нормалізація номерів телефонів;
- перевірка наявності клієнта та створення нового запису за потреби.

Також було реалізовано допоміжні функції `normalize_phone()` та `get_or_create_customer()`.

#### 3.3. Створення таблиці промокодів

Було створено SQL-файл `schema/03_promo.sql`, у якому реалізовано таблицю `promo_codes`.

Вона використовується для зберігання інформації про промокоди магазину.

| Поле | Призначення |
|---|---|
| `id` | Унікальний ідентифікатор промокоду |
| `code` | Назва промокоду |
| `discount_percent` | Відсоток знижки |
| `min_order_amount` | Мінімальна сума замовлення |
| `is_active` | Статус активності промокоду |
| `expires_at` | Дата завершення дії |
| `created_at` | Дата створення промокоду |

Для промокодів передбачено унікальність коду та перевірку допустимого значення знижки — більше 0% і не більше 100%.

#### 3.4. Реалізація керування промокодами

У файлі `routes/promo.py` було реалізовано функціонал керування промокодами.

Основні можливості:

- створення нових промокодів;
- перегляд списку промокодів;
- активація та деактивація промокодів;
- видалення промокодів;
- перевірка відсотка знижки;
- перевірка мінімальної суми замовлення;
- перевірка терміну дії промокоду.

Також реалізовано функції `find_valid_promo()` та `promo_discount()` для пошуку дійсного промокоду й обчислення розміру знижки.

#### 3.5. Створення адміністративних сторінок

Для зручного керування даними було створено дві HTML-сторінки:

- `templates/admin/customers.html` — сторінка перегляду, пошуку та керування клієнтами;
- `templates/admin/promo.html` — сторінка створення, перегляду та керування промокодами.

Сторінки інтегровано з адміністративною частиною вебзастосунку Flowery.

### 4. Забезпечення безпеки

Також було перевірено синтаксис Python-файлів за допомогою команди:

```bash
python -m py_compile routes/customers.py routes/promo.py
```

Перевірка завершилася без помилок. Додатково було перевірено завантаження маршрутів застосунку та ініціалізацію бази даних.
