# 🌸 Flowery — вебсайт квіткового магазину

Лабораторна робота №3. Базовий вебпроєкт на Flask + Tailwind CSS.

## Команда
- GinaWQ — каркас проєкту, меню, головна сторінка
- <нікнейм учасника 2> — сторінки «Про нас» і «Каталог»
- <нікнейм учасника 3> — сторінки «Доставка» і «Контакти»

## Запуск проєкту
1. Клонувати репозиторій: `git clone https://github.com/GinaWQ/Flowery.git`
2. Створити віртуальне середовище: `python -m venv .venv`
3. Активувати його:
   - Windows: `.venv\Scripts\activate`
   - macOS / Linux: `source .venv/bin/activate`
4. Встановити залежності: `pip install -r requirements.txt`
5. Запустити: `python app.py`
6. Відкрити в браузері: http://127.0.0.1:5000
